# Guion presentacion final EcoSense

Duracion sugerida: 8 a 10 minutos.

## Enfoque

La presentacion debe defender el alcance evaluado del ramo con seguridad, sin transformarlo en una lista de observaciones. La narrativa recomendada es:

1. EcoSense tiene una base tecnica fuerte, medible y versionada.
2. El bloque RF10-RF17 esta implementado y probado con TDD, BDD e integracion.
3. La estrategia de calidad cubre unitarias, escenarios Gherkin, glue code, integracion, SonarQube y rendimiento mobile.
4. E2E, carga/estres con Grafana y ampliacion al backlog completo se presentan como evolucion productiva si el alcance futuro lo requiere.

## Recorrido por laminas

| Lamina | Mensaje oral |
|---|---|
| 1 | Presentar el proyecto y declarar el alcance evaluado: RF10-RF17 con evidencia versionada. |
| 2 | Resumir los resultados duros: 83 tests, 89.23% lines, 77.88% branches y mejoras de rendimiento. |
| 3 | Explicar que RF10-RF17 son los casos priorizados defendidos con trazabilidad completa. |
| 4 | Mostrar RF10-RF17 como bloque funcional real: grupos, ranking y recompensas. |
| 5 | Explicar arquitectura por capas: UI, ViewModel/Repository, servicios de aplicacion, dominio y puertos. |
| 6 | Conectar casos de uso con servicios y tipos de evidencia. |
| 7 | Presentar la estrategia de calidad: unitarias, BDD, integracion, Sonar y performance. |
| 8 | Explicar TDD + BDD con ejemplos de RankingService y GrupoService. |
| 9 | Leer brevemente el ejemplo Gherkin y explicar que todos los escenarios definidos pasan. |
| 10 | Mostrar cobertura JaCoCo y comando reproducible. |
| 11 | Mostrar integracion IT-01 a IT-17 y explicar uso de dobles in-memory. |
| 12 | Presentar E2E como capa de madurez productiva posterior al alcance TDD/BDD. |
| 13 | Presentar carga/estres con Grafana como observabilidad operativa, no como nucleo del ramo. |
| 14 | Mostrar Sonar historico: Quality Gate OK, 0 bugs, 0 vulnerabilities, 20 smells. |
| 15 | Mostrar mejoras de performance mobile: APK y startup. |
| 16 | Cerrar con roadmap de evolucion posterior al alcance. |
| 17 | Concluir: base solida, evidencia reproducible y madurez tecnica defendible. |
| 18 | Usar como respaldo para rutas del repo y preguntas. |

## Frase de cierre recomendada

> EcoSense no se presenta solo como una app funcional, sino como un proyecto defendible por evidencia: pruebas, cobertura, BDD, integracion, SonarQube y rendimiento medido. Las capas E2E y Grafana quedan como evolucion natural para una etapa de operacion productiva.
